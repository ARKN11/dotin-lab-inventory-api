# Dotin Lab Inventory Management API

An inventory management REST API built with Python and FastAPI as part of Dotin Lab backend engineering training.

## Project Goals

- Build a RESTful API using FastAPI.
- Implement product management and inventory operations.
- Validate request data using Pydantic.
- Integrate PostgreSQL in later development stages.
- Practice professional backend engineering and Git workflows.

## Current Development Stage

FastAPI Fundamentals

The initial version will implement product CRUD operations using in-memory storage.

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
- uv
- PostgreSQL (planned)

## Project Status

Educational project under active development.
